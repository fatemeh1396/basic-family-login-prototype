BASIC FAMILY - نسخه‌ی اولیه‌ی پروتوتایپ واجهه کاربری
============================================================

درباره پروژه
============================================================

Basic Family یک پلتفرم خانوادگی است که افراد را در یک محیط امن و خصوصی به هم متصل می‌کند.

این پوشه شامل نسخه‌ی اولیه‌ی پروتوتایپ واجهه کاربری است که تنها برای نمایش معماری و سازماندهی UI طراحی شده است.

این نسخه شامل:
- صفحه‌ی ورود
- داشبورد مدیریتی (فقط برای مالک)
- داشبورد کاربر عادی
- سیستم حفاظت مسیر
- سیستم نماد SVG محلی
- طراحی مستوحی از Fluent Design

صفحه‌ی ورود
============================================================

فایل: index.html

صفحه‌ی ورود یک واجهه‌ی حرفه‌ای را ارائه می‌دهد که شامل:

- عنوان: Basic Family
- عنوان فرعی: ورود به حساب کاربری
- فیلد نام کاربری
- فیلد رمز عبور با دکمه‌ی نمایش/پنهان
- دکمه‌ی ورود
- دکمه‌ی "فراموشی رمز عبور" (غیرفعال - برای نسخه‌های بعد)
- دکمه‌ی "ثبت‌نام" (غیرفعال - برای نسخه‌های بعد)
- بخش وضعیت پروتوتایپ

منطق احراز هویت نمونه‌ای
============================================================

این نسخه احراز هویت واقعی را پیاده‌سازی نمی‌کند.

احراز هویت صرفاً روی sessionStorage انجام می‌شود.

حساب آزمایشی مالک:
- نام کاربری: owner
- رمز عبور: BF-Owner-2026

رفتار:

اگر نام کاربری و رمز عبور با اطلاعات مالک مطابقت داشتند:
  ✓ نقش: owner
  ✓ هدایت به: pages/admin.html

اگر نام کاربری و رمز عبور خالی نیستند (اما مالک نیستند):
  ✓ نقش: user
  ✓ هدایت به: pages/user.html

اگر نام کاربری یا رمز عبور خالی باشند:
  ✗ نمایش پیام خطا
  ✗ بدون هدایت

صفحه‌ی مدیر
============================================================

فایل: pages/admin.html

صفحه‌ی داشبورد مدیر یک واجهه‌ی حرفه‌ای را ارائه می‌دهد:

- Sidebar با گزینه‌های منو:
  • داشبورد
  • مدیریت کاربران
  • مدیریت محتوا
  • گزارش‌ها
  • تاییدیه و Moderation
  • اعلان‌ها
  • تنظیمات

- Header با:
  • عنوان صفحه
  • اطلاعات کاربر
  • دکمه‌ی خروج

- محتوای اصلی:
  • بخش خوش‌آمدید
  • کارت‌های اطلاعاتی
  • معماری نقش‌ها

حفاظت صفحه:
- فقط کاربرانی که basicFamilyRole === 'owner' می‌توانند وارد شوند
- در غیر این صورت به صفحه‌ی ورود هدایت می‌شوند

آرشیتکچر نماد‌های SVG محلی
============================================================

پوشه: assets/icons/

این پروژه از نماد‌های SVG محلی استفاده می‌کند (بدون CDN خارجی).

نماد‌های مورد نیاز:

جایی‌گذاری نماد‌های شما
============================================================

اگر نماد‌های SVG خود دارید (مثلاً از Tabler Icons):

1. نماد‌های SVG را از دانلود شده‌ی خود استخراج کنید
2. آن‌ها را در پوشه‌ی assets/icons/ قرار دهید
3. نام‌های فایل را مطابق با فایل‌های موجود نام‌گذاری کنید
4. هیچ تغییری در HTML/CSS لازم نیست

مثال:
assets/icons/eye.svg (جایگزین شده با نسخه‌ی شما)
assets/icons/home.svg (جایگزین شده با نسخه‌ی شما)
...

sessionStorage و حفاظت مسیر
============================================================

استفاده از sessionStorage:

کلیدها:
- basicFamilyRole: نقش کاربر (owner یا user)
- basicFamilyUsername: نام کاربری

حفاظت صفحه:

صفحه‌ی Admin (pages/admin.html):
- اگر basicFamilyRole !== 'owner' → هدایت به index.html

صفحه‌ی User (pages/user.html):
- اگر basicFamilyRole !== 'user' → هدایت به index.html

خروج
============================================================

دکمه‌ی خروج:

1. حذف basicFamilyRole از sessionStorage
2. حذف basicFamilyUsername از sessionStorage
3. حذف از localStorage (اگر استفاده شده باشد)
4. هدایت به صفحه‌ی ورود (index.html)

سیستم طراحی (Design System)
============================================================

تمام رنگ‌ها، فاصله‌گذاری و استایل‌ها در css/style.css به صورت متغیرهای CSS تعریف شده‌اند.

متغیرهای اصلی:

رنگ‌ها:
--bg: رنگ پس‌زمینه‌ی اصلی
--surface: سطح درخشان (کارت‌ها، پنل‌ها)
--surface-strong: سطح قوی‌تر
--text: متن اصلی
--text-secondary: متن دوم
--text-muted: متن کم‌رنگ
--accent: رنگ تاکید (آبی)
--success: رنگ موفقیت (سبز)
--danger: رنگ خطر (قرمز)

فاصله‌گذاری:
--space-xs: 4px
--space-sm: 8px
--space-md: 16px
--space-lg: 24px
--space-xl: 32px

شعاع گوشه‌ها:
--radius: 8px
--radius-lg: 12px
--radius-sm: 4px

سایه‌ها:
--shadow: سایه‌ی استاندارد
--shadow-lg: سایه‌ی بزرگ
--shadow-sm: سایه‌ی کوچک

دستورات استفاده
============================================================

1. دانلود یا clone این مخزن

2. فایل‌های SVG را (اگر دارید) در پوشه‌ی assets/icons/ قرار دهید

3. فایل index.html را در مرورگر باز کنید

4. تست کنید:

   حساب مالک:
   - نام کاربری: owner
   - رمز عبور: BF-Owner-2026
   - نتیجه: صفحه‌ی Admin

   حساب معمولی:
   - نام کاربری: هر نام دیگری
   - رمز عبور: هر رمز دیگری
   - نتیجه: صفحه‌ی User

5. دکمه‌ی خروج را برای بازگشت به صفحه‌ی ورود کلیک کنید
