درباره این پوشه
============================================================

این پوشه برای ذخیره‌سازی نماد‌های SVG محلی است.

پروژه‌ی Basic Family از نماد‌های SVG محلی استفاده می‌کند و هیچ CDN خارجی (مثل Font Awesome یا Tabler CDN) را مورد استفاده قرار نمی‌دهد.

دلایل استفاده از SVG محلی:
✓ کار بدون اتصال اینترنت
✓ سرعت بیشتر (بدون بار شبکه)
✓ کنترل کامل بر نماد‌ها
✓ سبک‌بودن (فایل‌های SVG کم‌حجم)
✓ مسئولیت‌پذیری (بدون وابستگی به سرویس‌های خارجی)

جایی‌گذاری نماد‌های شما
============================================================

اگر نماد‌های SVG خود دارید (مثلاً دانلود شده‌ی Tabler Icons):

مراحل:
1. فایل‌های SVG را از دانلودی‌های خود استخراج کنید
2. تمام فایل‌های SVG را در این پوشه (assets/icons/) قرار دهید
3. اطمینان حاصل کنید که نام‌های فایل دقیقاً با نام‌های فهرست شده‌ی بالا مطابقت دارد

مثال:
assets/icons/eye.svg
assets/icons/eye-off.svg
assets/icons/home.svg
assets/icons/users.svg
...

اگر نماد شما نام‌های متفاوتی دارد:
- می‌توانید نام‌ها را تغییر دهید تا با فهرست مطابقت کند
- یا می‌توانید فایل‌های HTML و CSS را برای استفاده از نام‌های جدید تغییر دهید

نام‌گذاری و بهترین روش‌ها
============================================================

هنگام نام‌گذاری نماد‌ها، از رویدادهای زیر پیروی کنید:

✓ نام‌های lowercase (کوچک)
✓ استفاده از hyphens (-) برای جدا کردن کلمات
✓ نام‌های توصیفی (مثلاً: eye-off نه ey-of)
✓ پسوند .svg برای تمام فایل‌ها

درست:

نادرست:

استفاده در HTML
============================================================

نماد‌ها در HTML به صورت زیر استفاده می‌شوند:

از صفحه‌ی index.html:
<img src="assets/icons/eye.svg" alt="">

از صفحه‌های pages/ (مثل admin.html):
<img src="../assets/icons/eye.svg" alt="">

توجه به مسیرهای نسبی
============================================================

مسیر نسبی برای دسترسی به نماد‌ها اختلاف دارد:

اگر فایل در ریشه‌ی پروژه است:
src="assets/icons/home.svg"

اگر فایل در پوشه‌ی pages/ است:
src="../assets/icons/home.svg"

اگر فایل در پوشه‌ی js/ است:
src="../assets/icons/home.svg"

اگر فایل در پوشه‌ی css/ است:
url('../assets/icons/home.svg')

چگونگی استفاده در CSS
============================================================

نماد‌ها می‌توانند با CSS نیز استفاده شوند:

.some-element::before {
    content: '';
    background-image: url('../assets/icons/home.svg');
    width: 20px;
    height: 20px;
    display: block;
}

یا با mask:

.some-element {
    mask-image: url('../assets/icons/home.svg');
    width: 20px;
    height: 20px;
}

استفاده در JavaScript
============================================================

نماد‌ها می‌توانند به صورت پویا تغییر داده شوند:

// تغییر src یک المان img
const icon = document.querySelector('.toggle-icon');
icon.src = 'assets/icons/eye-off.svg';

// یا ایجاد المان جدید
const img = document.createElement('img');
img.src = 'assets/icons/home.svg';
img.alt = '';
document.body.appendChild(img);

موارد مهم درباره SVG
============================================================

1. دسترسی‌پذیری:
   - همیشه alt="" را برای نماد‌های تزیینی اضافه کنید
   - برای نماد‌های کاربردی، alt="توضیح" اضافه کنید
   - برای دکمه‌های نماد دار، aria-label استفاده کنید

2. اندازه:
   - SVG‌ها معمولاً انعطاف‌پذیر هستند
   - می‌توانید اندازه را با CSS کنترل کنید
   - مثال: width: 20px; height: 20px;

3. رنگ:
   - اگر SVG سفید یا شفاف است، می‌توانید رنگ را با CSS تغییر دهید
   - مثال: filter: invert(1);

4. پاسخ‌گویی:
   - SVG‌ها خودکاراً با صفحه پاسخ‌گو هستند
   - اندازه‌ی نماد‌ها را برای دستگاه‌های مختلف تطبیق دهید

نکات فنی
============================================================

فایل‌های SVG باید:

✓ معتبر و خوش‌ریختی SVG باشند
✓ شامل نماد باشند (رسم یا نماد)
✓ اندازه مناسب داشتند (معمولاً 24x24 یا 32x32)
✓ حاوی metadata غیر ضروری نباشند
✓ بهینه‌سازی شده باشند (بدون کد اضافی)

نحوه‌ی دانلود از Tabler Icons
============================================================

اگر از Tabler Icons استفاده می‌کنید:

1. https://tabler-icons.io را بازدید کنید
2. نماد مورد نظر را جستجو کنید
3. روی نماد کلیک کنید
4. SVG را دانلود کنید
5. فایل را در این پوشه (assets/icons/) قرار دهید
6. نام فایل را بررسی کنید و در صورت لزوم تغییر دهید

درخواست کمک
============================================================

اگر فایل‌های SVG دانلود شده‌ی خود را دارید:

1. آن‌ها را در این پوشه (assets/icons/) قرار دهید
2. نام‌های فایل را بررسی کنید
3. فایل‌های HTML برای مسیرهای صحیح بررسی کنید

اگر دسترسی سیستم عامل یا git مشکل دارید:
